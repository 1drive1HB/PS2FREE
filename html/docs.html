Portable PS2 Emulator Setup Guide

Copy the folders to any USB/PC and run. Everything is already pre-configured— just point it to your games folder and connect a controller.

Folder layout (keep names)

  • ps2EMULATOR_PORTABLE_PC_WIN\ → main portable package
  • ps2EMULATOR_PORTABLE_PC_WIN\pcsx2-qtPortable\pcsx2-qt.exe → emulator (run this)
  • ps2EMULATOR_PORTABLE_PC_WIN\ps2Games\ (or external D:\PS2_games\) → put game ISOs here
  • ps2EMULATOR_PORTABLE_PC_WIN\pcsx2-qtPortable\mymc-alpha-2.7\mymc.exe → tool to import saves

Quick start (3 steps)

  1. Copy:
    ps2EMULATOR_PORTABLE_PC_WIN\ to your USB drive (or to D:\PS2EMU\).
  2. Put your PS2 games (.iso, sometimes .bin/.cue) into:
    • Portable folder:
      ps2EMULATOR_PORTABLE_PC_WIN\ps2Games\
    • OR external folder:
      D:\PS2_games\
  3. Run:
    ps2EMULATOR_PORTABLE_PC_WIN\pcsx2-qtPortable\pcsx2-qt.exe

Add the games folder inside PCSX2

If you don't see games after starting PCSX2:

  1. Open Settings → Game List.
  2. Click Add Game Directory.
  3. Choose ONE folder:
    • ...\ps2EMULATOR_PORTABLE_PC_WIN\ps2Games\
      (if you keep games inside the package), OR
    • D:\PS2_games\
      (if you keep games outside)
  4. Click Select Folder.
Tip: In the folder picker, click This PC → choose the drive letter (USB might be E: or F:) → open the folder → Select Folder.

Controller (USB or Bluetooth)

  • USB: plug it in, then start PCSX2.
  • Bluetooth: pair it in Windows first, then start PCSX2.
  • Works with PC controllers and PS4/PS5 controllers.

Saves (memory card only)

This pack does NOT cover save states (those are handled by your separate web/save-state app).

For normal "PS2 memory card saves", use myMC to insert saves into a memory card file:

  • Run:
    pcsx2-qtPortable\mymc-alpha-2.7\mymc.exe

    Use it to import downloaded save files into your PS2 memory card image (so the game can load it normally).
