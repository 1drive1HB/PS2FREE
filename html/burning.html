PS2 DVD burning Guide

System Context: This procedure has been verified on a PS2 Slim (SCPH-75004). While PS2 Fat models often have higher tolerance for various media, Slim models require strict adherence to these settings for successful reads.

2. Media Requirements

  • Format: DVD-R 4.7GB
    • Strict Requirement: Do not use DVD+R or DVD-RW.
  • Recommended Brands: Verbatim, Sony, TDK.
Tested on PS2 Fat: MODEL: SCPH-50004

3. Burning with ImgBurn

A. Initial Setup

  1. Launch ImgBurn.
  2. Select Write image file to disc from the main menu.

B. Load Image File

  1. Click the Browse button (folder icon).
  2. Navigate to and select your target .ISO file.
Settings: Tool = Write, Speed = x4, Copies = 1

C. Burn Settings

These settings are critical for PS2 Slim compatibility.

  • Write Speed: Set to 4x.
    • Note: 4x provides maximum stability. Use 8x only if 4x is unsupported by your media.

D. Burn Process

  1. Insert a blank DVD-R.
  2. Click the large Write button.
    • Verify: Checked (Ensures data integrity).
    • Eject Tray: Checked (Eject disc after completion).
    • Close Program: Checked (Exit after completion).
  3. Allow the process to verify and finish. Approximate 5-15 min for one .ISO range between 1GB - 4.7GB.
  4. After auto EJECT (because we enabled Eject Tray + Close Program), DVD-R is now READY for use!

4. Troubleshooting & Conversion

Conversion: BIN to ISO

Perform this step only if the game exists as a BIN/CUE file or if the PS2 refuses to read the standard burn.

Using gBurner:

  1. Launch gBurner.
  2. Navigate to Tools → Convert Image.
  3. Select your source .BIN file.
  4. Set output format to Standard ISO Image (.ISO).
  5. Select your destination folder and click Convert.
  6. Once converted, burn the new .ISO using ImgBurn (refer to Section 3).
Note: Retain original BIN/CUE files until the new ISO is tested and working.

Common Read Errors & Solutions

If the console fails to load the disc, follow this diagnostic hierarchy:

  1. Speed Check: Re-burn the image at 4x speed, regardless of previous success at higher speeds.
  2. Media Verification: Ensure the disc is DVD-R. Do not use DVD+R.
  3. Format Conversion: If the source was a BIN file, convert to ISO first. This is a known fix for persistent read errors on Slim models.
  4. Hardware Maintenance: Gently clean the laser lens using a cotton swab and high-percentage isopropyl alcohol.
  5. System Resources: Avoid using the PC for other tasks during the burning process to prevent buffer underruns.

Additional Notes

  • Disc Quality: Media brand and dye quality are the primary factors in read success.
  • Hardware Variance: A disc that works on a Fat PS2 may not work on a Slim due to different laser tolerances. Always test on the target hardware.

PS2 Backup Disc Formats

Original ISO (PAL/EU)

  • 1:1 sector-accurate disc dump
  • PAL region (Europe/Australia)
  • File extension: .iso
  • Uncompressed, unmodified
  • Optimal for burning with ImgBurn at 4x speed
  • Maximum compatibility with stock PS2 Slim

ISO File Variations

  • True 1:1 dumps: Full size (2–4.7 GB), best compatibility
  • Rebuilt ISOs: Modified structure, may shrink DVD9→DVD5, reduced compatibility
  • Compressed ISOs: Internal compression, .iso extension but incompatible

BIN/CUE Format

  • Standard for CD-based PS2 games (blue discs, ~200–700 MB)
  • Includes both .bin (data) and .cue (track layout) files
  • DVD games in .bin format indicate conversion (avoid)

File Identification

  • Proper PS2 DVD ISO: 2–4.37 GB, contains SYSTEM.CNF and region-specific executable
  • Proper PS2 CD BIN: 200–700 MB, accompanied by .cue file
