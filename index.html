Getting Started

  1. Navigate to the Releases page of this repository.
  2. Download the latest release archive (VCRedistAIO2025.11.25.zip).
  3. Extract the contents of the .zip file to a folder on your computer.
  4. Right-click on the 01. INSTALL ALL.bat script and select "Run as administrator".

How to use

  1. Download and extract the pack.
  2. Put games in ps2Games/
  3. Run
    pcsx2-qtPortable/pcsx2-qt.exe
  4. If game list is empty
    Settings → Game List → Add Game Dir
  5. Select ps2Games/ folder and click Select Folder
  6. Connect controller and launch a game.
Tip: On USB, if the drive letter changes, re‑select the ps2Games/ folder once.

Tools included

  • PCSX2 portable build
    pcsx2-qtPortable/pcsx2-qt.exe
  • myMC memory card tool
    pcsx2-qtPortable/mymc-alpha-2.7/mymc-gui.exe

Import save files

Use myMC app to import downloaded saves into memory card files.
