Portable PS2 emulator + utilities

Copy to USB. Run anywhere.

Everything is preconfigured. Just select your games folder and connect a controller. Play PS2 games on your PC.

Quick info

  • Windows 10/11 (64-bit)
  • Controller: USB or Bluetooth
  • Games: .iso format

Default folders

  • pcsx2-qtPortable\
  • ps2Games\

How to use

  1. Download and extract the pack.
  2. Put games in ps2EMULATOR_PORTABLE_PC_WIN\ps2Games\.
  3. Run pcsx2-qtPortable\pcsx2-qt.exe.
  4. If game list is empty: Settings → Game List → Add Game Directory.
  5. Select ps2Games folder and click Select Folder.
  6. Connect controller and launch a game.
Tip: On USB, if the drive letter changes, re-select the ps2Games folder once.
